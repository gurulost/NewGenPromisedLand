# Documentation Archive

This archive keeps old project artifacts available without letting them compete with current documentation.

Archive files are historical. They may contain stale paths, old validation results, outdated risk ratings, or instructions that were correct only for a past branch. Use them for context, not as the source of truth.

## Sections

- [checklists](./checklists/) - completed or stale production checklists and audit task logs
- [implementation-notes](./implementation-notes/) - one-time implementation summaries, model reports, testing reports, and bug-fix writeups
- [operations](./operations/) - old handoff, backup, branch, and audit notes
